Zoom to Learn, Learn to Zoom：从 Bayer RAW 直接超分，用光学变焦拍真值

CVPR 2019 的「真实数据超分」奠基作之一。论文主张：数字变焦（计算变焦）应该直接吃 12–14 bit 的 Bayer RAW，而不是吃被 ISP 降噪、压到 8 bit 的 RGB。难点是 RAW 没有高分辨率真值，于是作者用一支 24–240mm 变焦镜头对同一场景拍 7 档焦距，长焦 RGB 当短焦 RAW 的真值，攒出 500 组序列的 SR-RAW 数据集。不同焦距拍出来的图必然有 40–80 像素的错位（视差、景深、清晰度差），像素损失会糊，所以作者在 Contextual Loss 上加了空间坐标项，提出 CoBi 损失。 结果：4X 下 PSNR 26.88 / LPIPS 0.190，比最好的 RGB 基线高 3.75 dB；受控实验里同一网络吃真 RAW 比吃 8-bit RGB 高 4.54 dB，比吃合成 RAW 高 2.90 dB。代码只开源了推理、数据对齐和 CoBi 损失本体，训练脚本没放出来。从代码看，CoBi 的「空间项」实际退化成了「同位置特征加 0.1 分」，和论文 Eq. 2 写的「按距离惩罚」并不一样。

Unprocessing：把网上的 sRGB 照片逐步「逆 ISP」回 RAW，造出逼真的去噪训练对

Google Research 的 CVPR 2019 工作。真实 RAW 去噪数据难采，合成数据又不像真 RAW，于是作者把一张普通 sRGB 照片按相机 ISP 的反向顺序逐步「解处理」：逆 smoothstep 色调曲线 → 逆 gamma → 乘 sRGB→相机 RGB 的 CCM → 带高光保护地除掉白平衡与数字增益 → 抽成 RGGB 马赛克。在这份伪 RAW 上加按 ISO 联合采样的泊松-高斯（shot/read）噪声得到输入，再把网络输出和真值都过一遍简化正向 ISP 后算 L1。一个 22ms 的普通 U-Net 在 Darmstadt 真实噪声基准上 raw PSNR 48.89 / sRGB PSNR 40.35，相对此前最好的方法误差降低 14%–38%、快 9–18 倍。

RealSR：拧变焦环拍出真·低/高清配对，再用拉普拉斯金字塔核预测网络做真实世界超分

合成退化 (bicubic / 多种模糊+下采样) 训出的超分模型到了真实照片上几乎不比 bicubic 强。RealSR 的解法很朴素：三脚架固定单反，同一场景用 105mm 拍 HR、用 50/35/28mm 拍 LR，靠薄透镜公式给出初始缩放比，再用「仿射 + 亮度 α,β」的鲁棒 IRLS 逐级配准到像素级，得到 595 对真实退化配对 (Canon 5D3 + Nikon D810)。模型侧提出 LP-KPN：对 Y 通道做三层拉普拉斯金字塔、每层预测逐像素 5×5 核，等效 4k×4k 感受野。同样网络，换 RealSR 训练在 ×2 上涨约 1 dB；LP-KPN 以 5.7M 参数略胜 RCAN (32.7M)。代码里训练损失其实是三层金字塔各一个 L2 (1:1:1)，与论文写的「重建图上的 L2」不同。

手机照片 → 相机画质：细节与质感迁移调研（2017→2026）

专项「把 iPhone 照片（优先 Bayer RAW）在细节与质感上变成某台目标相机的效果」的入口调研。按五组覆盖本站刚精读的 12 篇：A 手机→单反画质（DPED / WESPE / PyNET / LiteISPNet / ISPW / DiffRAW / ISPDiffuser），B 用更好的光学拍真值（Zoom-to-Learn / RealSR），C RAW 域造数据（Unprocessing），D 跨相机颜色（C5），E 多帧（Handheld MFSR）。逐篇给出核心贡献、方法、带数字的结果和代码位置，再用一张矩阵按输入域、监督、对齐、颜色/纹理是否分离、骨干、数据集、代码对比，写出一致与矛盾。代码交叉验证汇总各页发现，其中有三条会直接影响复用：ISPDiffuser 发布版颜色一致性损失恒为 0、Canny 纹理损失无梯度、评测取 best-of-10；C5 的 apply_cst 原地覆盖导致 3×3 算错；ZRR 和 ISPW 都不提供单反 RAW。最后对照「物理颜色 + 多帧真实细节 + 强度可控的高频生成 + 目标相机 ISP 出图」这条管线，列出每一步的证据和缺口。

DiffRAW：用扩散模型把手机 RAW 变成单反观感——RAW 管结构、确定性 ISP 输出锁颜色和位置、扩散只补细节

DiffRAW（AAAI 2024，清华深研院 + 华为）第一次把扩散模型用到「手机 RAW → 单反 sRGB」的学习式 ISP 上，分工是：手机 RAW 当条件，负责轮廓和纹理结构；一张确定性 sRGB（训练时是单反图的合成退化版，测试时是 LiteISPNet 的输出）当「颜色-位置保持条件」，锁住颜色和像素位置；扩散模型负责补出单反级的高频细节。 为了少走几步，它还设计了 DTDM：前向过程边加噪边从 y 往 x 退化，于是推理可以直接从「加噪后的 LiteISPNet 输出」出发，100 步以内做完。ZRR 上 LPIPS 0.187→0.145、FID 17.04→15.10，无参考指标与单反真值持平，但 PSNR/SSIM 反而比 LiteISPNet 低一点。没有官方代码。

C5：看几张同一台相机的无标注照片，就能给没见过的相机做白平衡

C5（Google Research，ICCV 2021 Oral）想解决跨相机的自动白平衡：一个模型用多台相机训练，部署到没见过的传感器上仍然准。做法是在经典的卷积色彩恒常（CCC）外面套一层超网络：把待处理图和同一台相机拍的另外几张无标注照片都转成 log-chroma 直方图，网络读完这一组图后，为这台相机现场生成 CCC 的滤波器 F 和偏置 B。 在 Cube+、INTEL-TAU、NUS 等数据集的留一相机协议下，平均角误差 1.77°–2.52°，优于 SIIE、FFCC 等方法；模型约 2 MB，GPU 上每张约 7 ms。附录的数据增广把源相机 RAW 经 DNG 色彩矩阵转到 CIE XYZ，再映射到目标相机空间。这个做法和「iPhone RAW → 目标相机」的颜色对齐思路基本一致，同色异谱问题论文也坦白讲了。

DPED：把手机 JPEG 翻译成单反画质，「颜色、纹理、内容」三路分开监督

DPED 先造了一个同步拍摄的「手机 ↔ 佳能 70D」配对数据集（iPhone 3GS / BlackBerry / Sony 各约 14–16 万个 100×100 对齐 patch），再用一个 4 残差块的全卷积网络做端到端翻译。 核心是把损失拆成三份：模糊后比颜色、灰度判别器比纹理、VGG relu5_4 比内容，三者都对配对图之间几像素的错位不敏感。SSIM 三台手机全部第一，用户研究里「增强图 vs 单反原图」基本是五五开。
